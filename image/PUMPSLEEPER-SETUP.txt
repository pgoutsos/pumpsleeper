================================================
 PumpSleeper Setup
================================================

Before booting:
1. Open pumpsleeper.conf in a text editor
2. Hotspot (required): set HOTSPOT_SSID and HOTSPOT_PASS. This is the
   Wi-Fi network your PumpSpy device connects to so PumpSleeper can see it.
3. Home Wi-Fi (only if you are NOT using ethernet): set HOME_WIFI_SSID and
   HOME_WIFI_PASS so the Pi can reach the internet to install. If you have an
   ethernet connection, first boot uses it automatically and you can leave
   these blank.
4. Optionally set SSH_PASS to change the default login password
5. Save and eject the SD card

Default SSH login:
  Username : pumpsleeper
  Password : pumpspy  (change via SSH_PASS in pumpsleeper.conf)

On first boot, PumpSleeper installs automatically (3-5 minutes).
Progress is logged to pumpsleeper-install.log on this drive.

Once complete:
  Dashboard : http://pumpsleeper.local:8080   (or http://<pi-ip>:8080)
  SSH       : ssh pumpsleeper@pumpsleeper.local   (or <pi-ip>)

More info: https://github.com/pgoutsos/pumpsleeper
